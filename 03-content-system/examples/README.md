# Examples Library

This folder contains visual references.

## Structure

- drafts/ — newly created concepts
- pending-review/ — promising but not approved
- approved/ — validated examples
- approved/gold-standard/ — best-in-class DesHive examples
- rejected/ — archive of examples that do not fit the brand

Every approved example should include:
- image (PNG)
- source file (if available)
- short review (Markdown)
- QA score
