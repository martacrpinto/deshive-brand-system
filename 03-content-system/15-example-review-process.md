# Example Review Process

## Workflow

1. Idea
2. Draft
3. Self-review
4. Compare with Design System
5. Compare with Approved Examples
6. Run QA Checklist
7. Approve or Reject
8. Archive

### Decision

- 65–70: Approved
- 50–64: Pending review
- Below 50: Rejected

Only approved work may be added to `examples/approved/`.
Only exceptional work belongs in `examples/approved/gold-standard/`.
